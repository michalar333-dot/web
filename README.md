# mám capacitu – web mamcapacitu.cz

Předprodejní web kšiltovek s hláškou.

- `index.html` – celý web
- `ochrana-udaju.html` – zásady ochrany osobních údajů
- `img/` – náhledy výšivek (`q{hláška}-c{barva}.jpg`)
- `_podklady/google-tabulka-skript.js` – Apps Script, který ukládá rezervace do Google tabulky (na web se nenahrává)

Hosting: GitHub Pages s doménou mamcapacitu.cz (soubor `CNAME`). Každá změna ve větvi `main` se na web nasadí sama.
